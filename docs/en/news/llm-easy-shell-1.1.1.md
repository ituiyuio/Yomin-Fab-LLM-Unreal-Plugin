# LLMEasyShell v1.1.1

> 🚢 **Documentation maintenance patch on top of v1.1.0.** v1.1.1 ships no code
> changes — the C++ runtime, build artifacts, and Live Coding preflight remain
> identical to v1.1.0. This release focuses exclusively on the skill docs,
> experience library, and forensic archive.

## ✨ Unchanged from v1.1.0

All v1.1.0 features are unchanged:

- **Agent runtime** — TCP listener (ports 15151–15200) accepting plain text commands, returning JSON. Any LLM agent loop, CLI, or test harness can drive the Unreal Editor end-to-end.
- **36 built-in editor commands** — scene read/write, asset read/write, property/function reflection, PIE control, Live Coding, log capture, UI introspection, screenshots.
- **48 built-in Python abilities** (266 sub-commands across all host projects) — drop a `.py` into `Content/Python/LLMShellAbilities/abilities/` and it becomes invocable as `python <name>`.
- **C++ Ability framework** (untouched) — plugins register typed commands via `ULLMEasyShellAbilityCommandObject`.
- **Live Coding + Restart** — `livecoding` / `lc` / `reload` + `--restart` editor with crash detection.
- **PIE control + Slate composite screenshots** — `play` / `stop` / `pause` / `select` / `focus` + straight-to-PNG screenshots.
- **UI introspection + simulated input** — dump UMG widget trees, click buttons, type text.
- **Co-existence with LLM Easy Shell Lite** — separate port range (Lite on 15201–15250).

## ⚙ Requirements (unchanged)

- Unreal Engine 5.5 / 5.6 / 5.7 / 5.8 (one Project Version per UE)
- 9 engine plugin dependencies (see `README.md`): `PythonScriptPlugin`, `GameplayAbilities`, `GameplayTagsEditor`, `EnhancedInput`, `PoseSearch`, `Chooser`, `StructUtils`, `Niagara`, `EditorScriptingUtilities`
- `WebBrowserWidget` enabled in host `.uproject` for CEF-state UI introspection

## 📝 Known Limitations (unchanged)

- Live Coding and `log --compile` are Windows-only.
- First PIE / WebBrowser load may take 3–5 s on cold start; not a bug.
- `ModelContextProtocol` (`mcp` command) only active on UE 5.8+ (auto-stubbed on older).
- `WITH_LLMEASYSHELL_CODEO=0` (default Fab HostProject) → UI E2E helpers return `host_codeo_required` JSON.
